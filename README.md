# مسابقة تصويت البوسترات | كلية الغد

موقع لمشاركة البوسترات والتصويت عليها، أُعدّ ضمن أعمال فريق متدربات البرمجة في كلية الغد للعلوم الطبية التطبيقية – فرع جدة.

## رابط الموقع

[اضغط هنا لفتح الموقع](https://cheery-peony-b7703a.netlify.app/)

## مميزات الموقع

- تسجيل بيانات المشارك: الاسم الثلاثي، الرقم الأكاديمي، البريد الجامعي، والفئة طالب أو طالبة.
- رفع بوسترات بصيغ JPG وPNG وWEBP وPDF، بحجم يصل إلى 5 ميجابايت.
- عرض الأعمال برقم مشاركة دون إظهار اسم صاحبها في بطاقة المعرض.
- التصويت لأكثر من بوستر، مع منع تكرار التصويت لنفس الرقم الأكاديمي على نفس البوستر.
- عرض أعداد البوسترات والأصوات.

## التقنيات المستخدمة

- HTML وCSS وJavaScript لبناء واجهة الموقع.
- Supabase لقاعدة البيانات وتخزين البوسترات.
- Netlify لاستضافة الموقع.
- GitHub لحفظ الأكواد والتعاون بين أعضاء الفريق.

## ملفات المشروع

- public: ملفات واجهة الموقع والصور وإعداد الاتصال بـ Supabase.
- supabase: ملفات SQL المحفوظة لإعداد قاعدة البيانات وتعديلها.

ملاحظة: مجلد supabase يحتوي حاليًا على تعديل التسجيل والتصويت، ولم تُضف نسخة كود إنشاء الجداول الأول بعد. البوسترات وبيانات المشاركين والتصويتات محفوظة في Supabase ولا يتضمنها هذا المستودع.
